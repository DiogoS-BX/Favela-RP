# Assets da home

Exporte do Figma e salve nesta pasta **com estes nomes** — a página já aponta para eles.
Enquanto um arquivo não existir, aparece uma caixa tracejada com o nome dele no lugar.

| Arquivo | O que é | Formato |
|---|---|---|
| `logo-favela-gaming.svg` | Logo Favela Gaming (branco) — header e rodapé | SVG |
| `logo-league-royale.svg` | Logo League Royale Favela Gaming (com "LEAGUE" em cima) | SVG |
| `logo-claro-branco.svg` | Logo Claro branco (patrocínio no topo) | SVG |
| `logo-claro.svg` | Logo Claro escuro (faixa de parceiros) | SVG |
| `hero-arte.png` | Arte da direita do topo: menino + personagens, fundo transparente | PNG 2x |
| `dragao.png` | Card do bebê dragão (com o fundo amarelo) | PNG 2x |
| `menina-celular.jpg` | Foto da menina com o celular | JPG 2x |
| `requisitos-jogadores.png` | Dupla de jogadores da seção Requisitos, fundo transparente | PNG 2x |
| `logo-clash-royale.png` | Logo Clash Royale | PNG 2x |
| `logo-gerando-falcoes.svg` | Logo Gerando Falcões | SVG |
| `logo-youtube-gaming.svg` | Logo YouTube Gaming | SVG |
| `logo-final-level.svg` | Logo Final Level Co. | SVG |
| `logo-cpn.svg` | Logo CPN (rodapé) | SVG |
| `favicon.png` | Ícone da aba do navegador (opcional) | PNG 64x64 |
